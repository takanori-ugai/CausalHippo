\abstract{
本稿では、LightRAGの評価結果を用いて、ナレッジグラフ（KG）の品質とGraph-Based RAGの検索性能および生成品質との関係を調査した。E0ではMuSiQue 15サンプルにおいて、ER=0.844、RR=0.589、Support Recall@5=0.611、Token F1=0.033、Faithfulness=0.472であった。E1では抽出LLMの能力を変化させ、E2ではKGへの摂動を加え、検索・生成指標の変化を比較した。
}

\section{はじめに}

大規模言語モデル（Large Language Model: LLM）の急速な発展に伴い、外部知識源から関連情報を動的に取得して回答を生成する検索拡張生成（Retrieval-Augmented Generation: RAG）\cite{lewis2020rag}が広く実用化されている。従来のNaive RAGは、テキストを固定長チャンクに分割して密ベクトル埋め込み（Dense Embedding）の類似度検索を行う手法が主流であった。しかし、このアプローチでは、複数文書にまたがるエンティティ間の関係性を辿る多段推論（Multi-hop Reasoning）や、コーパス全体のトピック構造を俯瞰して回答を要約する質問に対して、関連チャンクの想起漏れや文脈の断片化が生じやすいという限界が指摘されている。

これらの課題を克服するため、非構造化テキストコーパスから自動的にエンティティや関係性を抽出してナレッジグラフ（Knowledge Graph: KG）を構築し、グラフ構造と探索アルゴリズムを検索・プロンプティングに統合した「Graph-Based RAG」が注目を集めている。先行研究として、階層的コミュニティ検出と要約を用いるGraphRAG \cite{edge2024graphrag}、低レベル（エンティティ）と高レベル（関係・テーマ）の二層インデックスを統合したLightRAG \cite{guo2024lightrag}、関係パスの探索と枝刈りを行うPathRAG \cite{chen2024pathrag}、海馬の記憶想起に着想を得てオープン情報抽出（Open Information Extraction: OpenIE）とPersonalized PageRank（PPR）を組み合わせたHippoRAG \cite{gutierrez2024hipporag}、スキーマ駆動抽出とスキーマ進化を備えたYoutuRAG \cite{dong2025youtu}などが提案されている\cite{pan2024unifying}。

しかしながら、既存のGraph-Based RAG研究における評価は、主に「特定データセットにおける最終的な質問応答（QA）精度」のエンドツーエンドの比較にとどまっており、\textbf{「中間生成物であるKG自体の品質（エンティティ抽出精度、関係抽出精度、グラフ密度、トポロジー構造）が、下流の検索性能や回答生成品質にどのような因果的メカニズムで影響を及ぼしているのか」}という点は十分に解明されていない。Graph-Based RAGにおいてKG構築はLLMを用いた情報抽出に依存しているため、抽出漏れ、幻覚（ハルシネーション）による誤ったエッジ、重複エンティティ、グラフの断片化などの品質劣化が発生する。したがって、KGのどの品質次元が検索・推論の成否に関係するのかを定量的に明らかにすることは、Graph-Based RAGシステムを設計する上で重要な学術的・実践的課題である。

そこで本研究では、異なるKG構築・検索アプローチを持つ5系統のGraph-Based RAG（GraphRAG, LightRAG, PathRAG, HippoRAG, YoutuRAG）を同一の実行基盤上で統合的に評価し、KG品質が検索対象ノードの発見率、推論経路の妥当性、および最終的な回答品質に与える影響を多角的に分析した。具体的には、以下の4つの研究疑問（Research Questions: RQ）を設定した：
\begin{itemize}
    \item \textbf{RQ1（KG構築特性の差異）}：5つの手法が同一テキストから構築するKGは、抽出精度およびグラフ構造特性（密度・次数分布・連結性）においてどのように異なるか？
    \item \textbf{RQ2（検索性能への影響メカニズム）}：KG品質指標は、検索対象ノードの発見率や推論経路の妥当性とどのように連動・相関するか？
    \item \textbf{RQ3（最終生成品質への波及）}：KG品質および検索精度の差異は、最終回答品質（Token F1, Faithfulness等）までどの程度直接的に波及するか？
    \item \textbf{RQ4（支配的品質次元の特定）}：抽出Recall、抽出Precision、グラフ密度、構造ノイズのうち、Graph-Based RAGの性能を最も強く支配する要因はどれか？
\end{itemize}

本論文の主な貢献は以下の通りである：
\begin{enumerate}
    \item \textbf{KG品質とGraph-Based RAG性能の評価体系の構築}：エンティティ想起率（ER）、エンティティ適合率（EP）、重複実体率（DER）、関係想起率（RR）、関係適合率（RP）、抽出失敗率（EFR）、グラフ密度・トポロジー指標に加え、新たに「KG-Coverage (KGC)」「Retrieval-Hit@K (RH@K)」「Discovery Conversion Rate (DCR)」「Chain-In-Graph (CiG)」「Chain-In-Context (CiC)」といった検索対象ノード発見率・推論経路妥当性を測定する指標を導入・定式化した。
    \item \textbf{5系統のGraph-Based RAGの比較}：同一のコーパスおよび評価設定（生成LLM固定・埋め込みモデル固定）のもとで、5系統のKG構築特性と検索性能を測定・比較した。
    \item \textbf{KG品質操作および摂動実験による寄与の検証}：抽出LLMの能力階層操作（E1）および構築済みグラフに対する意図的摂動（E2：ランダム削除、推論キー実体の選択的削除、ノイズ注入）を実施し、KG品質と回答性能の関係を検証する。
\end{enumerate}


\section{関連研究}

本節では、Graph-Based RAGの主な構築・検索方式、近年のアーキテクチャの展開、およびKG品質とRAG性能を評価する研究を整理し、本研究の位置づけを示す。

\subsection{評価対象とするGraph-Based RAG手法とその類型}
Graph-Based RAGは、テキストから抽出したエンティティや関係をグラフとして組織化し、その構造を検索対象の選択やコンテキストの構成に利用する手法群である。既存研究は、グラフの構築方式と、検索時にどの粒度の情報を集約するかという観点から整理できる\cite{pan2024unifying}。本研究の評価対象である5手法は、次のように位置づけられる。
\begin{enumerate}
    \item \textbf{階層的コミュニティ要約型（GraphRAG）}：GraphRAG \cite{edge2024graphrag} は、コミュニティの階層と要約レポートを用いて、広い範囲を対象とする質問に対応する。
    \item \textbf{二層検索型（LightRAG）}：LightRAG \cite{guo2024lightrag} は、エンティティを対象とする低レベル検索と、トピックや関係を対象とする高レベル検索を組み合わせ、異なる粒度の情報を取得する。
    \item \textbf{関係パス探索型（PathRAG）}：PathRAG \cite{chen2024pathrag} は、クエリに関連するエンティティ間の関係パスを探索し、候補パスを枝刈りしてコンテキストを構成する。
    \item \textbf{神経生物学着想型（HippoRAG）}：HippoRAG \cite{gutierrez2024hipporag} は、エンティティ間の類似性を利用したネットワーク探索により、クエリに関連するパッセージを検索する。
    \item \textbf{スキーマ駆動・進化型（YoutuRAG）}：YoutuRAGは、スキーマに基づき構造化された知識を用いて、対象領域に適応した検索を行う\cite{dong2025youtu}。
\end{enumerate}

\subsection{Graph-Based RAGアーキテクチャの新しい方向性}
上記の手法に加えて、近年はグラフ構築の計算量、抽出誤り、検索時の柔軟性を改善する方向で研究が進められている\cite{pan2024unifying}。主な方向性は次の4つに整理できる。
\begin{itemize}
    \item \textbf{グラフ構築コストの削減}：関係ラベルの抽出を減らし、エンティティ・文・パッセージの共起や軽量なリンクを利用する方式が検討されている。LinearRAGは関係抽出を用いないTri-Graphを構築し、インデックス構築の線形スケール化を目指している\cite{zhuang2025linearrag}。
    \item \textbf{ニューラル検索との統合}：グラフニューラルネットワーク（Graph Neural Network: GNN）などを用いてグラフ上の構造的な対応や推論経路を推定し、得られたサブグラフを自然言語化してLLMに入力する方式が提案されている。GNN-RAGはGNNで候補ノードを評価し、関連エンティティを結ぶ最短経路をLLMのコンテキストとして利用する\cite{mavromatis2025gnnrag}。
    \item \textbf{エージェントによる動的探索}：LLMがグラフ上で候補の展開、枝刈り、再検索を反復し、質問に応じて探索範囲を調整する方式である。Think-on-GraphはLLMエージェントによるグラフ探索を導入し\cite{sun2023thinkongraph}、StructRAGはタスクに応じて表・木・グラフなどの構造を選択する\cite{li2024structrag}。また、MemGraphRAGは共有メモリを用いたマルチエージェントによるグラフ構築を検討している\cite{xiang2026memgraphrag}。探索の柔軟性が得られる一方、推論段階のモデル呼び出し回数が増える可能性がある。
    \item \textbf{ドメイン特化型の構造化}：医療や因果推論などの領域では、オントロジー、階層関係、因果制約をグラフに組み込み、根拠の追跡や推論上の制約を明示する設計が検討されている。MedGraphRAGは医療文書と医学的な語彙・情報源を接続する階層的なグラフ構築とU-Retrievalを提案している\cite{wu2024medicalgraphrag}。
\end{itemize}
これらの研究は、グラフを固定的な検索インデックスとして扱うだけでなく、構築時のコスト、検索時の探索、ドメイン知識の制約を一体として設計する方向を示している。本研究ではこの動向を踏まえ、特定のアーキテクチャの優劣を論じるのではなく、KG構築の品質と検索・推論過程の関係を共通指標で評価する。

\subsection{GraphRAGの評価とグラフ構築の評価}
従来のGraph-Based RAG研究では、特定データセットにおける質問応答（QA）の最終性能を比較する評価が中心であった。この評価は実用上の性能を捉えられる一方、グラフ構築、検索、推論のどの段階が結果に影響したかを分離しにくい。そこで近年は、各処理段階を分けて評価する枠組みが提案されている。
Xiaoら\cite{xiao2025graphragbench}は、ドメイン特化型ベンチマーク「GraphRAG-Bench」において、グラフ構築（Graph Construction）、知識検索（Knowledge Retrieval）、回答生成（Generation）、推論過程（Reasoning / Rationale）を対象とする評価体系を提示した。

この中でXiaoらは、GraphRAGにおけるグラフ構築方式を以下の4類型に整理している：
\begin{itemize}
    \item \textbf{Tree構造}（例: RAPTOR）：チャンクの反復クラスタリングと要約により階層木を構築する。
    \item \textbf{Passage Graph}（例: KGP）：チャンクをノードとし、エンティティリンキングツール等により実体間エッジを結ぶ。
    \item \textbf{Knowledge Graph (標準KG)}（例: HippoRAG, G-Retriever等）：OpenIE等によりチャンクからエンティティと関係（トリプル）を抽出して構築する。
    \item \textbf{Rich Knowledge Graph}（例: GraphRAG, LightRAG）：標準KGに対し、LLMを用いて実体や関係の詳細な要約記述・属性情報を付与してリッチ化する。
\end{itemize}
さらにXiaoらは、グラフ構築の品質とコストを測定する指標として、\textbf{効率性（Efficiency: 構築時間）}、\textbf{計算コスト（Cost: LLMトークン消費量）}、および\textbf{構造組織化の品質（Organization: 非孤立ノード比率）}の3軸を導入した。
同ベンチマークは、構築方式の違いを、構築時間、LLMトークン消費量、非孤立ノード比率という異なる側面から比較する。Tree構造、Passage Graph、標準KG、Rich KGでは、必要なモデル呼び出し、リンク処理、要約・属性生成の範囲が異なるため、効率性と組織化の指標に異なる傾向が生じる。この整理は、最終QA性能だけでなく、性能と構築コストのトレードオフを検討する際の基準を与える。

\subsection{KG品質とRAG性能の関係および本研究の位置づけ}
ナレッジグラフの品質は、トリプルの正確性、完全性、一貫性、重複実体の名寄せ（Entity Resolution）などの観点から評価されてきた。また、言語モデルによる因果関係抽出やファクトチェックを対象とするベンチマークも提案されている\cite{ugai2025,trivedi2022musique}。これらの品質は、検索対象となるノードや経路の形成を通じて、RAGの応答品質に影響し得る。
上述のGraphRAG-Benchは構築コスト・時間と非孤立ノード比率を評価するが、抽出時の実体想起率（ER）や関係想起率（RR）といった要因が、対象実体の発見率（RH@K, DCR）や推論連鎖の連結性（CiG, CiC）を介して最終性能に及ぼす影響は、別途検討する必要がある。さらに、意図的な構造摂動に対する耐性も、構築品質と検索・推論の関係を検証する上で重要である。
本研究は、既存のグラフ構築分類と構造評価を踏まえ、KG品質、検索、推論連鎖を対応付けた評価体系を構築する。これにより、摂動実験を用いて各段階の指標と最終回答品質との関係を分析する。


\section{評価対象システムとKG構築メカニズム}

本研究で評価対象とした各システムの実装は、公平な比較と同一実行基盤上での精密な制御のために、Kotlin言語を用いて新規に移植・実装したものである。各手法のプロンプトは原著の設計を可能な限り忠実に維持・再現しているが、統一パイプラインへの適応や構造化パースの安定化に伴う軽微な調整が含まれている。評価対象とする5手法について、実装で用いた抽出処理、エンティティ統合、グラフ拡張の手順を以下に記述する。
\begin{enumerate}
    \item \textbf{GraphRAG}: 各チャンクからエンティティと関係性をJSON形式で同時抽出し、エンティティ記述を要約（\texttt{SummarizeDescriptionsWorkflow}）した上で、Leidenアルゴリズムにより階層的コミュニティ構造を形成する。
    \item \textbf{LightRAG}: 単一プロンプトから実体と関係を抽出し、名前をキーとして重複実体をマージする。抽出結果にはエンティティ記述、関係記述、キーワードなどを付与する。
    \item \textbf{PathRAG}: 構造化JSONプロンプトによりエンティティと関係のトリプルを抽出し、各エンティティと関係をグラフ形式で保存する。
    \item \textbf{HippoRAG}: 第1段階で固有表現抽出（NER）を行い、第2段階で抽出された固有表現に基づいて事実トリプルを抽出する（2フェーズOpenIE）。構築された二部グラフ（Passage-Entity-Fact）に対し、エンティティ間の埋め込みコサイン類似度が閾値（デフォルト0.80）以上のペアに「同義エッジ」を自動付与する。
    \item \textbf{YoutuRAG}: 事前に定義されたオントロジースキーマに従って抽出し、テキスト中に出現した未知の概念型をスキーマへ動的に取り込みながらTreeCommアルゴリズムによりコミュニティを検出する。
\end{enumerate}

\section{評価指標体系の定式化}

本研究では、KGの抽出品質とグラフ構造特性、中間検索レイヤにおける発見率・経路妥当性、および最終的な生成品質を統合的に評価する指標体系を構築した。

\subsection{正解基準（Gold Annotations）の定義}
各指標を同一の基準で算出するため、データセットごとに正解実体、正解関係、および推論連鎖の参照集合を定義する。
\begin{itemize}
    \item \textbf{多段推論正解集合（MuSiQue）}：質問分解ステップ $q_d[1..N]$ の各ステップの正解実体および最終回答のエイリアス集合を正解実体集合 $E_{\text{gold}} = \{q_d[i].\text{answer}\} \cup \{\text{answer}\} \cup \text{aliases}$ とする。また、推論の依存関係を結んだ正解パスを $C_{\text{gold}} = (e_1 \to e_2 \to \dots \to e_m)$ と定義し、始点から終点に至る推論連鎖の中間ステップを繋ぐ実体を\textbf{ブリッジ実体（Bridge Entity）}と呼ぶ。
    \item \textbf{因果関係正解集合（Causal-Reasoning-QA）}：メタデータに付与された原因実体と結果実体を $E_{\text{gold}} = \{\text{cause}, \text{effect}\}$ とし、正解因果エッジを $R_{\text{gold}} = (\text{cause} \to \text{effect})$ とする。
    \item \textbf{テキスト正規化・照合判定}：小文字化、冠詞除去、記号正規化、部分文字列一致、および埋め込み類似度（閾値0.85）により、抽出実体と正解実体の同値性を判定する。
\end{itemize}

\subsection{KG抽出品質指標（KG Extraction Quality Metrics）}
正解基準および原文との一致に基づいてKGの抽出品質を評価するため、以下の指標を用いる。
\begin{enumerate}
    \item \textbf{Entity Recall (ER)}: 正解実体集合 $E_{\text{gold}}$ のうち、構築されたKGのノード集合 $V_{\text{KG}}$ に含まれる割合：
    \begin{equation}
        \text{ER} = \frac{|V_{\text{KG}} \cap E_{\text{gold}}|}{|E_{\text{gold}}|}
    \end{equation}
    \item \textbf{Entity Precision (EP)}: 抽出されたノード集合 $V_{\text{KG}}$ のうち、元文書テキスト $T$ に根拠を持つ（正規化表記またはエイリアスが出現する: $v \in T$）ノードの割合（文書グラウンディング率）：
    \begin{equation}
        \text{EP} = \frac{|\{v \in V_{\text{KG}} \mid v \in T\}|}{|V_{\text{KG}}|}
    \end{equation}
    \item \textbf{Duplicate Entity Ratio (DER)}: 抽出ノード集合 $V_{\text{KG}}$ における近似重複ノードペア集合 $P_{\text{dup}}$ の割合（名寄せ能力の評価）：
    \begin{equation}
        \text{DER} = \frac{|P_{\text{dup}}(V_{\text{KG}})|}{|V_{\text{KG}}|}
    \end{equation}
    \item \textbf{Relation Recall (RR)}: 正解因果エッジ $R_{\text{gold}}$ または正解推論連鎖 $C_{\text{gold}}$ の各ステップを結ぶエッジ／パス（長さ $\le 3$）のうち、KG内に存在するものの割合。
    \item \textbf{Relation Precision (RP)}: 抽出されたエッジ集合 $E_{\text{KG}}$ のうち、両端点ノードが元文書テキスト内に出現する（$u, v \in T$）割合（虚偽エッジ抑制率）：
    \begin{equation}
        \text{RP} = \frac{|\{(u, v) \in E_{\text{KG}} \mid u, v \in T\}|}{|E_{\text{KG}}|}
    \end{equation}
    さらに、同一パッセージ（段落 $p \subset T$）内に共起して出現する割合を $\text{RP}_{\text{co-occur}}$ として算出する。
    \item \textbf{Extraction Failure Rate (EFR)}: LLMの出力構文の不備によりJSONまたはスキーマのパースに失敗したチャンク数を、処理対象チャンク数で割った割合。
\end{enumerate}

\subsection{グラフ構造特性指標（Graph Structural Metrics）}
構築されたKGの規模、疎密、および連結性を記述し、手法間の構造的な差異を比較するため、以下の指標を用いる。これらは正解基準との一致を直接測るKG抽出品質指標ではない。
単純無向グラフを仮定したグラフ密度（$\text{Dens} = \frac{2|E|}{|V|(|V|-1)}$）、ノード数 $|V|$、エッジ数 $|E|$、平均次数 $\bar{k}$、次数ジニ係数 $G_k$、孤立ノード率（Isolated Node Ratio: INR）、最大連結成分比率（$R_{\text{LCC}} = \frac{|V_{\text{LCC}}|}{|V|}$）を算出する。

\subsection{検索対象ノード発見率・推論経路妥当性の新設指標}
Graph-Based RAGの核心的プロセスである「KG上での対象実体・推論パスの捕捉」と「検索コンテキストへの引き上げ」を評価するため、以下の新設指標を導入した：
\begin{enumerate}
    \item \textbf{KG-Coverage (KGC)}: KGインデックス側に正解実体が存在する割合。本稿の定義では式(1)のERと同じ値であり、検索可能なインデックス上で評価したERをKGCと呼ぶ。
    \item \textbf{Retrieval-Hit@K (RH@K)}: 検索された上位 $K$ 件のコンテキスト内に正解実体集合 $E_{\text{gold}}$ が出現する割合：
    \begin{equation}
        \text{RH@K} = \frac{|\{e \in E_{\text{gold}} \mid e \in \text{Context}_{\text{top}K}\}|}{|E_{\text{gold}}|}
    \end{equation}
    \item \textbf{Discovery Conversion Rate (DCR)}: KG上に存在していた正解ノードが、検索アルゴリズムによってどれだけ上位コンテキストへ変換（引き上げ）されたかの比率：
    \begin{equation}
        \text{DCR} = \frac{\text{RH@K}}{\text{KGC}} \quad (\text{ただし } \text{KGC} > 0)
    \end{equation}
    \item \textbf{Chain-In-Graph (CiG)}: 正解推論連鎖 $C_{\text{gold}} = (e_1 \to e_2 \to \dots \to e_m)$ の全実体間にKG上でパスが存在し、始点から終点まで連結しているかを表す二値指標（0または1）。
    \item \textbf{Chain-In-Context (CiC)}: 検索された上位 $K$ 件のコンテキストが、推論連鎖に含まれるすべてのブリッジ実体を網羅しているかを表す二値指標（0または1）。
\end{enumerate}

\subsection{検索精度および回答生成品質指標}
KGから取得された根拠が検索結果と最終回答にどの程度反映されたかを評価するため、検索指標と回答生成指標を用いる。
\begin{itemize}
    \item \textbf{検索精度}：正解根拠段落の想起率を表す \texttt{Support Recall@K}（$K=1,3,5$）、\texttt{MRR@5}、\texttt{nDCG@5}。
    \item \textbf{回答品質}：正解テキストと生成回答間のトークン重複に基づく \texttt{Token F1}、および検索コンテキストに対して生成回答が事実に即しているかをLLMが評価する忠実性指標 \texttt{Faithfulness}（LLM-as-a-Judge）。
\end{itemize}


\section{実験設計}

実験では、データセット、モデル、検索条件を統制した上で、ベースライン比較、抽出モデルの能力操作、構築済みKGへの摂動を順に実施する。

\subsection{実験データセット}
本実験では、推論特性の異なる以下の3つのデータセットを用いた。評価にあたっては、各データセットから無作為に抽出した15サンプルのサブセットを使用した：
\begin{enumerate}
    \item \textbf{MuSiQue} \cite{trivedi2022musique}：2〜4ホップの質問分解アノテーションが付与されたマルチホップQAデータセット。多段推論連鎖（$C_{\text{gold}}$）およびブリッジ実体の検証に使用。
    \item \textbf{Causal-Reasoning-QA}：原因と結果の明示的なペア（$R_{\text{gold}}$）および真偽ラベルが付与された因果関係QAデータセット。因果エッジの抽出精度と正当性の検証に使用。
    \item \textbf{Webis-CausalQA-22} \cite{bondarenko2022causalqa}：Web文書に基づく大規模な因果質問応答データセット。グラフ構造の正解アノテーションを持たないオープンコーパスにおける一般化性能と生成品質の検証に使用。
\end{enumerate}

\subsection{実験構成と統制条件}
交絡因子（Confounding Factors）を厳密に統制するため、以下の条件を設定した：
\begin{itemize}
    \item \textbf{回答生成LLMの固定}：全実験・全手法において、回答生成モデルを \texttt{qwen3.8:27b}、temperature $=0$、固定seedに統一した。これにより、回答品質の差異を主としてKGおよび検索コンテキストの品質の差として比較した。
    \item \textbf{埋め込みモデルの固定}：\texttt{nomic-embed-text} に統一した。
    \item \textbf{検索パラメータ}：top-$K = 5$、コンテキストトークン上限を共通化。
\end{itemize}

\subsection{実験マトリクス}
研究疑問に対応するため、通常条件での比較に加えて、抽出LLMの能力を変化させる実験と、KGの構造を操作する実験を設定した。
\begin{itemize}
    \item \textbf{E0（ベースライン比較実験）}：強抽出モデル（\texttt{qwen3.8:27b}）を用いて5系統×3データセットにおけるKG品質と検索・生成性能のベースラインを測定した（RQ1, RQ2）。
    \item \textbf{E1（抽出LLM能力操作実験）}：生成LLMを固定したまま、KG構築を担う抽出LLMのパラメータ規模・能力水準を3段階（強: \texttt{qwen3.8:27b}［27B］、中: \texttt{gemma4:e4b}［9Bクラス］、弱: \texttt{llama3.2:3b}［3B］）に変化させ、抽出能力の低下に伴うKG品質および下流性能の劣化傾向を定量化した（RQ3）。
    \item \textbf{E2（KG事後摂動実験）}：構築済みKGに対して意図的な構造操作（摂動）を加え、どの品質次元（エッジ欠落、キー実体の欠落、属性テキストの有無、構造ノイズ等）が性能劣化に最も強く寄与するかを比較した（RQ4）。摂動条件は以下の通りである：
    \begin{itemize}
        \item \textbf{P0（無変更 / Control Base）}：摂動を加えない基準グラフ。
        \item \textbf{P1（ランダムエッジ削除）}：グラフ全体から一様無作為にエッジを間引き（削除率10\%, 30\%, 50\%）、関係の疎密化（Relation Recall低下）の影響を検証。
        \item \textbf{P2（ランダムノード削除）}：グラフ全体から一様無作為にノードを削除し（削除率10\%, 30\%）、実体想起率（Entity Recall）の一般的な低下影響を検証。
        \item \textbf{P3（正解キー実体の選択的削除）}：正解推論連鎖（$C_{\text{gold}}$）を構成するブリッジ実体および回答実体のみを選択的にグラフから完全削除し、推論上不可欠な実体の欠落が及ぼす影響を検証。
        \item \textbf{P4（テキスト記述削除）}：ノードやエッジに付与された要約文・説明記述・テキスト情報をすべて削除してグラフ構造（トポロジー）のみを残し、テキスト属性情報の寄与度を検証。
        \item \textbf{P5（構造ノイズ注入）}：元文書に存在しない無作為な偽ノードおよび偽エッジを注入し（注入率10\%, 30\%）、幻覚（ハルシネーション）や不要エッジ等のノイズに対する頑健性を検証。
    \end{itemize}
\end{itemize}

\subsection{システム設計への示唆}
以上の実験結果から、Graph-Based RAGのシステム設計に関して以下の点が示唆される：
\begin{enumerate}
    \item \textbf{抽出・検索・生成の分離評価}：E0ではER=0.844、RR=0.589、Support Recall@5=0.611、Token F1=0.033であり、KG品質だけで最終回答品質を説明できない。
    \item \textbf{摂動効果の限定的評価}：E2ではKGC、RH@5、CiG、CiC、Support Recall@5、Faithfulnessを条件間で比較できるが、15サンプルという小標本であるため、因果効果の断定は避けるべきである。
\end{enumerate}


\section{おわりに}

本稿では、LightRAGの評価結果（E0、E1およびE2）を用いて、ナレッジグラフの品質と検索・回答生成品質の関係を分析した。エンティティ抽出精度、関係抽出精度、グラフ構造指標に加え、検索対象ノード発見率（KGC, RH@K, DCR）および推論経路妥当性（CiG, CiC）を測定する評価指標系を適用した。

実験の結果、LightRAGのE0（15サンプル）ではER=0.844、EP=0.946、RR=0.589、Support Recall@5=0.611、Token F1=0.033、Faithfulness=0.472であった。E1では抽出LLMの変更によりMuSiQueのERは0.747〜0.867、Token F1は0.032〜0.036の範囲となった。E2では10条件を各15サンプルで完了し、P1のエッジ削除やP2・P3のノード削除によりCiGが低下した。Token F1は0.024〜0.032、Faithfulnessは0.395〜0.541であり、摂動による包括的な因果的効果は今後の課題として残る。

今後の課題として、ドメインオントロジーの活用による抽出精度の向上、動的に更新されるコーパスに対する増分KG品質管理手法の開発、およびマルチモーダルGraph-Based RAGへの拡張が挙げられる。
